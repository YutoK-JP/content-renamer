# Theme Comment Writer

macOS向けのRust GUIアプリです。Finderからファイルをドラッグ&ドロップすると、MP3 / M4A のタイトルタグとアーティストタグをもとに AnimeThemes API で曲名を検索し、関連しそうなアニメ作品の候補を集めます。候補の作品名は、AniList から日本語の正式タイトルを引ける場合はそちらを優先します。候補には OP / ED / etc. の種別も付き、選んだ内容を `作品名 [OP]` 形式で音声ファイルの `Comment` タグへ記録します。

## 使い方

```bash
cargo run
```

起動後は次のどちらかでファイルを渡せます。

- Finderからウィンドウへドラッグ&ドロップ
- `ファイルを選択` ボタンから選択

タイトルタグが入っていない MP3 / M4A は検索対象にできません。アーティストタグがある場合は候補の優先順位付けにも利用します。

## コメントの書き込み

候補検索後、プルダウンから作品名と種別を選んで保存します。既存コメントがある場合は残しつつ、次の形式の行を追加または更新します。

```text
ドラえもん [OP]
```

## 注意点

- MP3 は ID3 の `Comment` タグ、M4A は iTunes style の `©cmt` コメントを更新します。
- 検索はまず AnimeThemes の曲名一致を優先し、見つからない場合だけ AnimeThemes の全文検索で関連候補を広げます。
- 英語・ローマ字の作品名は AniList の `native` タイトルで日本語化を試み、結果はローカルキャッシュして問い合わせ回数を抑えます。
- AnimeThemes API ベースのため、現状の対象は主にアニメ作品です。一般映画や実写作品はカバーできません。
- オープニングなら `OP`、エンディングなら `ED`、それ以外は `etc.` として保存します。
